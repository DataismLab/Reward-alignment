## Code and data availability

The simulation experiments use data generated by the accompanying code. The controlled neural and PPO experiments use conditional samples from the specified regime model. The known-covariance experiments use separately generated synthetic data.

The historical analysis uses publicly available monthly value-weighted US industry portfolio returns and factors from Kenneth French's Data Library. The archived files are in `data/raw/`:

| Archived input | Original public source |
|---|---|
| `10_Industry_Portfolios_CSV.zip` | [10 industry portfolios](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/ftp/10_Industry_Portfolios_CSV.zip) |
| `30_Industry_Portfolios_CSV.zip` | [30 industry portfolios](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/ftp/30_Industry_Portfolios_CSV.zip) |
| `49_Industry_Portfolios_CSV.zip` | [49 industry portfolios](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/ftp/49_Industry_Portfolios_CSV.zip) |
| `F-F_Research_Data_Factors_CSV.zip` | [Fama–French research factors](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/ftp/F-F_Research_Data_Factors_CSV.zip) |

The reported historical comparisons use the August 2026 vintage and evaluate January 1990 through December 2025, with moments estimated from the preceding 120 months. The archived files contain additional observations outside that evaluation period. These are revised research portfolios rather than a point-in-time investable stock universe.

Source URLs, retrieval dates and SHA-256 hashes for the 10-industry and factor files are recorded in [the download record](results/september26_downloads.json). [The dimension-study manifest](results/historical/dimensions/manifest.json) records the 10-, 30- and 49-industry vintages, retrieval dates and hashes. Retrieval dates differ across files. Use the archived inputs and their hashes to reproduce the reported sample; downloading a later version can change the results.

The historical allocation analysis and the simulated-market RL experiments have separate data and evaluation designs. The manuscript defines the reported experiments.

## Reproduction materials

The [main README](README.md) gives installation, verification and experiment commands. In particular:

- `scripts/check_outputs.py` checks saved benchmark outputs.
- `scripts/finalise_rl_results.py` reconstructs the final neural and PPO comparisons from saved policies.
- `scripts/check_historical.py` and the covariance verification scripts check the historical outputs.
- Experiment runners specify simulation seeds and numerical settings.
- `results/rl-extension/final-environment.txt` records the environment used for the final learning experiments.

Record the exact Git commit, input hashes, experiment configuration, seed and software environment with any reproduced result. Reconstruction from saved outputs and retraining are different operations; the README identifies their commands and output paths.
